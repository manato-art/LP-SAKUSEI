## なぜ進められないか

本案件の方法は **capture-and-rehydrate**（採取した実物のHTML/CSSをそのまま土台にし、
挙動だけローカルのモックへ配線する）で、**手書きで似せることは禁止**されています（企画書 §5）。

上記9項目は**採取物が1つもありません**。観測記録（`docs/findings-live-observation.md`）にも
サイドバーのラベルとして名前が出てくるだけで、画面の中身は一度も記録されていません。

そして **2026-09-01 の作業中、本番アプリへのアクセスが権限の判定で拒否されました。**
そのため新しく採取することができません。

```
mcp__claude-in-chrome__navigate → Permission denied by the auto mode classifier
```

拒否を迂回することはしていません（迂回してはいけない種類の制限です）。

## 進めるために必要なこと（人間の操作が要ります）

次のどちらかです。

1. **ブラウザ操作の許可を出す**
   許可が出れば、私が各画面を開いて（**閲覧のみ・GETのみ**）採取し、匿名化して土台にできます。
2. **採取だけ人にやってもらう**
   `docs/採取手順.md` の手順で、各画面を開いた状態で採取用スニペットを実行してもらえば、
   そのデータが `~/squadbeyond-capture-quarantine/` に入ります。あとは私が処理できます。

## 採取するときの注意（実データ）

- ダッシュボード・CV速報・ランキングは**実際の売上や配信金額が表示される画面**です。
  匿名化は強化済みで、DOM本文の金額・率も架空値へ置き換わります
  （`tools/scrub/dom-numbers.ts`。同じ実値は常に同じ架空値になるので表の合計は破綻しません）。
- フォルダ名などの顧客データは、サイドバーの一覧については行ごと落とします
  （`tools/scrub/folder-rows.ts`。クローンの基準は新規の空アカウントのため）。
- それでも取りこぼす実名はあります。見つけたら `.gate-names.local`（非コミット）へ
  追加してください。`npm run gate` が全932ファイルを走査して残存を検出します。
