# 到達性レポート（実機巡回・機械測定）

「このボタンを押す → 次の画面 → そこで押す → 次の画面」を機械的に辿った結果。
道具は `tools/reachability/crawl.js`（ブラウザで動かす）。目視ではなく、
画面の指紋（ハッシュ＋見出し＋data-test集合）で「別の画面へ移ったか」を判定している。

## 実行条件

- 起点: エディタ（Versionタブ）
- 深さ上限 3 / 試行上限 110 回
- 状態: 新規空アカウントに、フォルダ1・ページ1を**クローンの作成フローで**作った直後

## 結果

| 指標 | 値 |
|---|---|
| 到達した画面 | **20** |
| 行き止まり（押せる物が1つも無い画面） | **0** |
| 再訪失敗（同じ手順でたどり直せない） | **0** |
| 試行回数 | 110 |
| 未探索のまま残ったキュー | 1813 |

## 到達できた画面（20）

| 手順 | 画面 | その画面で押せる物 |
|---|---|---|
| 起点 | エディタ（Version） | 198 |
| タブ | 基本情報 | 94 |
| タブ | ポップアップ | 74 |
| タブ | レポート | 153 |
| ボタン | マスタースタイルシート（モーダル） | 201 |
| ボタン | HTML設定（モーダル） | 206 |
| サイドバー | ダッシュボード / AI / タスク / ページ / CV速報 / ツール / 外部連携 / ドメイン / 拡張機能 / レポート除外 / イベント・セミナー / ランキング（12件） | 72〜76 |
| その他 | カレンダー / メニュー項目 | 64 |

**サイドバー12項目はすべて遷移する**が、`ページ` 以外の11項目は
「まだ作っていない」と正直に表示する画面に着く（できているように見せていない）。
中身を作るには採取が要る（`docs/サイドバー12項目の状況.md`）。

## 分かること

- **タブの行き来・サイドバーの遷移・モーダルの開閉が、実際に押して動く**。
  静的な模写ではなく、押すと次の画面へ進む状態になっている。
- **行き止まりが0**。到達した11画面すべてに、さらに押せるものが残っている
  （＝「到達不可能まで」には届いていない。まだ先がある）。
- ヒートマップ画面はこの試行回数では到達しなかった。
  レポートのサブナビ経由なので起点から深さ3にあたる。

## この測定の限界

- 深さ2・試行70回で打ち切っている。キューが1187残っており、**全部は辿れていない**。
- 画面の指紋が同じだと「同じ画面」と見なす。見た目が同じで中身だけ違う遷移は数えられない。
- 押した結果が正しいか（実物と同じか）は見ていない。**移ったかどうか**しか見ていない。
  正しさは別途 `tests/` と評価チームの照合で担保する。
