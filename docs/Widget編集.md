# Widget編集（1つの画面）の決まり

2026-09-23 に「ノーコードで作る」（ライブラリの中の入力画面）と「Widget編集」（全画面）を1つにした（本人の決定 D1〜D3）。
この文書は、その画面の作り・保存の形・触るときの決まりの正本。詳しい理由は各ファイル先頭のコメントに書いてある。

## 画面の作り（widget-studio.ts）

全画面。**左＝見え方（620pxの見たまま画面）／右＝直すところ**。この左右は崩さない（本人指定）。

右は3段:

1. **画面のタブ**（`[data-widget-tabs]`）… 画面①②…
2. **部品** … 画面の設定／部品の一覧（選んだ1つを広げる）／部品を足す／Widget全体の設定（template-form.ts）
3. **デフォルト時のコードを表示** … Widget全体のHTML/CSS（widget-code-panel.ts。設定から書き出したものなので見るだけ）

ヘッダー: 閉じる／作成したWidgetに登録／**LPに入れる**（新しく作るとき）または **更新する**（LPの中のWidget）。

## 直し方は1つ（部品）— 2026-09-24 第3弾

本人の指摘「Widget編集とノーコードで作るで画面UIが2つある。ノーコードの方に合わせて、書式のツールバーだけは残して」。
以前あった「HTMLモード（要素ごとのカードとコードを右に出す）」は無くし、**どのWidgetも右は「部品」**。

| 開くもの | どう開くか |
|---|---|
| 部品で作ったWidget（外側に `data-nc-data`） | その設定データで開く |
| 設定データを持たないWidget（自作の見本・手書きのHTML・2026-09-23 より前の部品Widget） | `wrapHtmlAsBuilder`＝**見本の部品1つ**にして開く（余白0・背景「なし」で見え方は変えない）。部品が1つだけなら開いた直後にその部品を広げる |

見本の部品の中（form-sample.ts）に、以前のWidget編集にあった直し方を全部置いた:
- 文字・画像・動画・ボタン・囲み の欄と「押したとき」、設問①②…のタブ（前からあるもの）
- **見た目の細かい設定** ＝ 要素ごとのカード（widget-design-panel.ts。色・大きさ・余白・動き。数字はドラッグ＋スライダー）
- **コードで直す** ＝ この見本のHTML・CSS（色付きのコード欄。打ち終わると入力欄を組み立て直す）

左の見たまま画面:
- **書式のツールバーは常に出す**（太字・色・大きさ・フォント・リンク・画像…）。見出し・文章・ボタンなどの部品の文字も、ツールバーで付けた飾りごと持つ（`rich-text.ts`。持てるのは文字の飾りだけ＝b/i/u/s/span/font/br と色・大きさの style。script・img・a などは外す）
- 見本の部品の中を押すと、右でその部品が開き「見た目の細かい設定」がその要素のカードだけになる。左の枠もその要素に付く
- 画像の操作パネル・リンクの吹き出し・並んだ部品の複製/上下/消す は**見本の部品の中だけ**効く（見出しやボタンの部品は右の欄で直す）
- 道具が中身を変えたら `notifyCanvasEdit(contentDiv, 変えた要素)`（widget-canvas-events.ts）で知らせ、その要素の部品だけ設定データへ読み戻す
- Widget全体の上下の余白は「Widget全体の設定」か、何も選んでいないときの枠の上下の辺で
- 「デフォルト時のコードを表示」はWidget全体のコード（見るだけ）

## 保存の形（builder-data.ts）

```html
<style>…</style>
<div class="nc nc-builder nc-xxxxxxxx" data-nocode="builder" data-nc-data="{…JSON…}" data-nc-screens="true" …>…</div>
<script>…</script>
```

- `data-nc-data` は `TemplateData` を JSON にして属性にしたもの（`& " < >` はエスケープ）。読むときは戻す
- 画像・動画は data URL のまま JSON に入る。保存のとき本文と同じ規則で別ファイル（`/uploads/<ハッシュ>.<拡張子>`）に置き換わるので、
  開き直したときは `/uploads/…` の形になる。`kit.ts` の `safeImage` / `safeVideo` はこの形も受け付ける
- 見本の部品の中身（html）もそのまま JSON に入る
- 「部品を解除」は無い（第3弾で HTMLモードを無くした）。コードを直したいときは見本の部品の「コードで直す」

## 入口（全部この画面）

| 押すもの | 開き方 |
|---|---|
| ライブラリ「+ ノーコードで作る」 | ライブラリを閉じて、既定の中身で開く |
| 見本カード「画面を作って使う」 | ライブラリを閉じて、その見本を部品にして開く（設問①②③は画面①②③に分ける） |
| LPの中のWidgetをクリック／設置済みWidgetのカード | 設定データがあればそれで、無ければ見本の部品1つとして開く |
| 部品モードの「見本」を足す・「見本を選ぶ」 | この画面を隠してライブラリを開き、「追加」を押した見本を受け取って戻る（`openWidgetLibraryForPick`） |

## 触るときの決まり

- 左の見たまま画面の中身（contentDiv）は保存しない（保存は設定データからの書き出し）ので、編集専用の目印を付けてよい。
  ただし見本の部品の中身は DOM から読み戻す（innerHTML）ので、見本の中には目印を付けない（KB 2026-09-22-001）
- 選択枠・操作ボタンは contentDiv の**外の層**に置く（selection-layer.ts・item-toolbar.ts）
- 左の文字を打ち直したときは、その部品だけ読み戻す（`syncCanvasBlock`）。部品をまたぐ入力・打てない部品への入力は `beforeinput` で止める
- 部品の数え方は「画面をまたいで上から順の通し番号」（`nc-b-12`）。書き出し（builder.ts）と読み戻し（`blockPathAt`）で同じ数え方にする
- テストは純粋ロジックに切り出して vitest で固定する（builder-data・canvas-sync は linkedom）。画面そのものはブラウザで確かめる
- スマホは `mobile-css.ts` の `[data-widget-*]`（左右→上下）と `[data-nc-tab]`（入力欄の大きさ）がそのまま効く

## Canva 風の直接操作（第2弾・2026-09-23）

- **選択枠のつまみ**（selection-layer.ts）: 右の辺＝幅、下の辺＝高さ、右下の角＝文字の大きさ、上下の辺＝Widget全体の上下の余白。
  動かしている間は見た目だけ（`preview`）、離したら確定（`commit`）。値の計算は drag-math.ts（`dragValue`）
  - 部品: 画像・図形＝幅%、余白＝高さpx、見出し・文章＝文字の大きさpx、何も選んでいないとき＝Widget全体（上下の余白）。確定で設定データへ書いて描き直す
  - 見本の部品の中の要素: そのカードにある `width`/`height`/`font-size`（CSS変数は名前で見分ける `handleKindOf`）。画像・動画は幅%の直書き
- **数字の欄**（number-scrub.ts）: 名前や単位を左右にドラッグで増減（4pxで1刻み）＋下にスライダー（範囲は `sliderRange`）。部品の入力欄（form-controls.ts）と要素ごとのカード（widget-design-panel.ts）の両方
- **部品の並べ替え**: 右の一覧の頭をつかんでドラッグ（上半分に落とすと前、下半分で後ろ。`moveTo`）
- 見本の部品の「見た目の細かい設定」は、**左で押した要素のカードだけ**を出す。「全部のカードを見る」で一覧
- 大きさの選び（見出し 大/中/小・文章 標準/小さめ・余白 小/中/大・上下の余白 狭い/普通/広い）は**数（px）**に変えた。古い中身の文字（'l' など）は `legacy` の表で読み替える（`sizeOf`・number欄の `legacy`）
