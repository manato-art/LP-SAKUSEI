# クローンを触ってみる（所要2分）

## 起動

ターミナルを**2つ**開いて、それぞれで実行します。

**1つ目 ― データ（モックAPI）**

```bash
cd ~/Desktop/squadbeyond-clone && npm run mock
```

**2つ目 ― 画面**

```bash
cd ~/Desktop/squadbeyond-clone && npm run dev
```

ブラウザで **http://localhost:5173** を開きます。

---

## できること（新規アカウント発行直後の状態から始まります）

1. 左パネルの **「＋ フォルダ」** でフォルダを作る
2. **「＋ 新規ページを作成」** で beyondページを作る
   - エディターを選ぶ（beyondエディターのみ有効。他2つは実機どおり選択肢としては出ます）
   - ページ名を入れる
   - 広告媒体を選ぶ（実機と同じ65種類）
3. 作成すると **LPエディタ** に移動します
4. エディタでできること
   - 中央の白い枠をクリックして**文字を入力**
   - 入力した文字を**選択するとツールバーが出る**（太字・下線・斜体・打ち消し線・上付き・下付き・リンク・文字色・背景色・整列・書式・サイズ・フォント）
   - 左パネルで **Version名の変更・配信割合の入力・更新**（合計100%でないと警告が出ます）
   - **「＋ Version追加」** で Version を増やす
   - 右のツール: **PC / SP** のプレビュー幅切替、**コード編集**、**元に戻す / やり直す**、**画像を追加**、**保存**、**公開**
   - **公開**を押すと確認ダイアログが出て、状態バッジが「準備中 → 配信中」に変わります

右下の **「空の状態に戻す」** で、いつでも新規アカウント直後に戻せます。

---

## まだできないこと（正直な現状）

- **ダッシュボード・CV速報・タスクなど、ページ以外の画面**
  → 開くと「この画面はまだ作っていません」と表示されます
- エディタの **基本情報 / ポップアップ / レポート** タブ
- ファネル（中間ページ）、Widgetライブラリ、リンク置換、記事設定、タグ設定
- HTMLエディター（4ペインのコード編集画面）

## 見た目について

サイドバーは**採取した本物のHTMLとCSS**をそのまま使っています。
中央のエディタ部分は、本物と同じ **Quill** というライブラリで作っているので、
文字選択時のツールバーの挙動は実機とほぼ同じです。

一覧・モーダルの見た目は、まだ本物のマークアップに置き換えていません（動作を優先しました）。
採取が進めば、ここも本物の見た目に差し替えられます。
