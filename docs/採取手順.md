# 採取手順（人間がやる版・所要30〜45分）

普通にアプリを触るだけで、画面が自動保存されます。手でコピペする必要はありません。

---

## 準備（初回だけ・2分）

ターミナルで、クローンのフォルダに入ってモックサーバーを起動します。

```bash
cd ~/Desktop/squadbeyond-clone && npm run mock
```

`[mock] http://localhost:4010` と出たら準備完了です。**このターミナルは開いたままにしてください。**

## 採取（ここから本番）

1. Chrome で採取対象のアプリを開く
   - **サイドバー下の「新UI」トグルは OFF のまま**にしてください（旧UIが再現対象です）
2. `F12`（または `Cmd+Option+I`）で DevTools を開く
3. **Console** タブを選ぶ
4. `tools/capture-console/snippet.js` の中身を**全部コピーして貼り付け、Enter**
5. 画面右下に青いバッジ「採取モード: 待機中」が出れば成功

あとは**普通にアプリを触るだけ**です。

**クリックのたびに「画面が変わったか」を見て、変わっていたら自動で保存します。**
モーダル・ドロップダウン・パネルも、押した先が勝手に撮れます。
バッジが緑になって「保存OK (n件)」と増えていけばOKです。

保存名は押したボタンから自動で付きます（例: `Widget管理-3`、`プレビュー-7`）。

### 狙って撮りたいとき

自動で撮れなかった状態（ホバーだけで出るものなど）は、その状態を出したところで
**`Ctrl + Shift + S`** を押すと、名前を聞かれます。

### 終わるとき

Console で `__sbStop()` と打つか、タブを閉じてください。

## 撮ってほしい画面（優先順）

### 最優先 ―― LPエディタまわり

`beyondエディター` のページを開いて、以下を `Ctrl+Shift+S` で撮ってください。

| 状態 | 出し方 | 名前の例 |
|---|---|---|
| エディタ初期 | Versionタブを開いた直後 | `editor-default` |
| 文字を選択 | LP内の文字をトリプルクリック | `text-selected` |
| ツールバー展開 | 選択後に「⋮」を押す | `toolbar-expanded` |
| 書式メニュー | 「Normal」を押す | `format-menu` |
| 文字サイズメニュー | 「17px」を押す | `fontsize-menu` |
| フォントメニュー | 「serif」を押す | `font-menu` |
| 文字色 | ●を押す | `font-color` |
| 背景色 | ▢を押す | `bg-color` |
| 整列メニュー | ≡を押す | `align-menu` |
| リンク挿入 | 🔗を押す | `link-insert` |
| Widgetライブラリ | 右レールのパズルアイコン | `widget-library` |
| Widgetカテゴリ各種 | 左のカテゴリを切り替えるたび | `widget-見出し` など |
| 記事設定 | 右レールの⚙ | `article-settings` |
| タグ設定 | 右レールの`</>` | `tag-settings` |
| バージョン復元 | 右レールの時計 | `version-history` |
| リンク置換 | 右レールの指アイコン | `link-replace` |
| 画像追加 | 右レールの画像アイコン | `image-picker` |
| ヘッダー画像設定 | 「ヘッダー画像を追加する」 | `header-image` |
| Version追加後 | 「Version追加」を押した後 | `version-added` |
| 公開の確認ダイアログ | 公開ボタン（**確定は押さない**） | `publish-confirm` |

### 次 ―― 一覧・作成まわり

| 状態 | 出し方 |
|---|---|
| フォルダ未選択の`/folders` | ページを開いた直後 |
| フォルダ選択後 | フォルダをクリック |
| 行を選択した状態 | ページの行をクリック（ドロワーが出る） |
| 新規ページ作成モーダル | 「新規ページを作成」 |
| 作成モーダルの各セクション | スクロールしながら数枚 |
| フォルダ作成モーダル | 左上の新規フォルダアイコン |
| 検索で0件 | フォルダ内検索に適当な文字列 |

### 次 ―― サイドバーの各画面

ダッシュボード / AI / タスク / CV速報 / ツール / 外部連携 / ドメイン / 拡張機能 / レポート除外 / イベント・セミナー
を順に開くだけ（自動保存されます）。

---

## 注意

- **配信中のページは触らないでください。**（一覧の「配信ステータス」が `配信中` のもの）
- **公開ボタンは押さないでください。**確認ダイアログの見た目まででOKです
- 保存先はリポジトリの外（`~/squadbeyond-capture-quarantine/`）です。実データを含むので、
  **匿名化を通すまでリポジトリには入りません**

## 終わったら

私に「採取終わった」と伝えてください。匿名化 → チェック → 画面化まで自動で流します。

```bash
# （参考）私が実行するコマンド
npx tsx tools/scrub/index.ts --in ~/squadbeyond-capture-quarantine/routes --out capture/clean --host-pattern '...'
npm run gate        # 実データが残っていないか検査
npm run rehydrate   # 触れる画面に変換
npm run dev         # http://localhost:5173 で確認
```
