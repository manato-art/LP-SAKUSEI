# 【最重要・恒久ルール】本番アプリで触ってよい範囲

ページが完成するまで、**AIが本番アプリで触ってよいのは次の1画面だけ**。

```
ページ → 金谷 → ナイトエンペラー → 複製用 → バージョン（Versionタブ＝LPエディタ）
```

- 対象ページ: **`複製用`**（フォルダ `金谷 / ナイトエンペラー` 配下）
- 対象タブ: **Version（LPエディタ）**
- 状態: `準備中`・媒体は `媒体/ポストバックなし`・編集タイプ `beyondエディター`

## やってはいけないこと

- **上記以外のフォルダ・ページを開かない**（一覧の閲覧も最小限）
- **配信中のページには絶対に触れない**
- **公開ボタンを押さない**
- **他人が最終編集したページの「引き継ぎ」を押さない**
- 新規作成・削除をしない（採取用ページの追加作成も、明示の許可があるまでしない）

## API について

- **GET（読み取り）のみ**。POST / PUT / PATCH / DELETE は本番に対して一切叩かない
- 叩くのは上記1ページに関するものに限る

## このルールの位置づけ

指示（2026-08-31）による恒久ルール。**企画書の §3 Step0 と同格**として扱う。
以降のセッションでも、本番アプリに触れる前に必ずこのファイルを読むこと。
範囲を広げるときは、人間から明示の指示があった場合に限る。
