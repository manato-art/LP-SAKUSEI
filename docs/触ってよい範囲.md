# 【最重要・恒久ルール】本番アプリで触ってよい範囲

指示（2026-09-01）による更新。**企画書 §3 Step0 と同格**として扱う。
本番アプリに触れる前に必ずこのファイルを読むこと。作業の開始時と終了時の2回、読み直して確認する。

## ① 実データには一切手を加えない

- **実際に配信しているデータ／実データに関わるものは、触らない・変更しない・削除しない。**
- 閲覧（GET）はしてよい。**書き込み（作成・更新・削除・公開）はしない。**
- 実データが理由で「中身が見られない／再現できない」箇所が出たら、**直さずに記録**し、
  作業の最後に次の形式でまとめて報告する。

```
①
ページ→〇〇→〇〇→〇〇

②
ページ→〇〇→〇〇→〇〇
```

## ② 新しく作るものの名前には必ず「複製」を付ける

- 実データに影響しない範囲で新しくフォルダやページを作る必要が出たら、
  **その名前に必ず「複製」を含める**（例: `複製-検証用`）。
- 名前に「複製」が無いものを新規作成しない。

## ③ 既存フォルダは「重南」のものだけ触ってよい

- 既にあるフォルダを触るのは、**「重南」（人名）と記載されているものだけ**。
- **それ以外の既存フォルダ・ページには一切触れない**（一覧の閲覧は最小限）。
- 対象の具体名は `.touch-scope.local`（.gitignore 済み）で管理する。
  実名をこの文書に書くと実データがリポジトリへ入るため（実際に一度、実名がコミット済みになっていた）。

## やってはいけないこと

- 配信中のページに触れる
- 公開ボタンを押す
- 他人が最終編集したページの「引き継ぎ」を押す
- 「重南」以外の既存フォルダ・ページを開く／変更する
- 実データの削除・上書き

## API について

- **GET（読み取り）のみ。** POST / PUT / PATCH / DELETE は本番に対して一切叩かない。
- ただし **LPエディタを開くと本番側で `updated_at` が更新される**ことが観測されている
  （`docs/findings-live-observation.md`）。エディタを開く行為自体が書き込みを伴うため、
  **「重南」配下または自分で作った「複製」ページ以外ではエディタを開かない。**
