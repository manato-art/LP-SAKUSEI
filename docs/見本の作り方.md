# 自作の見本（Widgetライブラリ）の作り方

2026-09-23、本人の指示で SB由来の見本を全部外し、**自作の見本だけ**にした（目標100種）。
置き場は `src/app/panels/nocode/samples/`（1ファイル＝1本）、一覧は `index.ts`、土台は `kit.ts`。

確かめ: `npm run sample-check`（1本ずつの決まり）／ `npx vitest run tests/nocode-new-samples.test.ts`（全体）。

## 1本のファイルの形

```ts
/**
 * 新しい見本「〇〇」（2026-09-23）。
 * 何に使う区画か・なぜこの形にしたかを2〜4行で書く。
 */
import { INK_SUB, LINE_LIGHT, head, headCss, sampleHtml, type NewSample } from './kit.ts'

const UID = 'nc-xxxx0001'      // nc- ＋ 8文字（英小文字と数字）。ほかの見本と重ならないこと
const ACCENT = '#1F7AE0'       // このWidgetで使う色は1色だけ
const s = `.${UID}`            // CSSは必ずこの中

const CSS = headCss(UID) + `${s} .x-foo{…}` + `@media (max-width:480px){${s} .x-foo{…}}`

export const XXX_SAMPLE: NewSample = {
  id: 'xxx',                   // 英小文字とハイフン
  category: '特徴・価値',       // SAMPLE_CATEGORIES のどれか
  name: '見出しに出る名前（15〜25字）',
  summary: 'カードの下に出る一言（60字まで・何に使うかが分かる言い方）',
  html: sampleHtml({ uid: UID, css: CSS, body: head('見出し', 'リード') + '…' }),
}
```

最後に `index.ts` の `NEW_SAMPLES` へ、LPの上から下の順で足す。

## 守ること（`npm run sample-check` が見る）

1. **いちばん外は** `<div class="nc nc-sample nc-xxxxxxxx" data-nocode="sample">`（`sampleHtml` が作る）。
   LPに入れるたびに名前を付け替えるので、この形と `nc-` ＋8文字を崩さない
2. **CSSのセレクターは全部 `.nc-xxxxxxxx` から始める**。要素名だけの指定（`p{…}`）はLP全体を壊す
3. **外から何も読み込まない**。画像は `IMAGE_PLACEHOLDER`（data:）、印は kit の固定SVG。
   Webフォント・CDN・外部の画像URLは禁止（`https://` を書かない）
4. **`on〇〇=` / `javascript:` / `id="…"` を使わない**（同じLPに2つ入れても壊れないように）
5. **絵文字を使わない**（印は固定SVG）
6. 画面①②…を持つ見本は `screens: { transition, script: SCREENS_SCRIPT }` を渡し、
   最初の画面だけ見えている形（`screen(..., { first: true })`）。`data-nc-go` の先は自分の画面のidだけ

## 見た目の決まり（人が見るところ）

- **白地・余白広め・素直な形**（本人の決定）。どのLPに入れても浮かない中立な作り
- **色はWidgetごとに1色**。強調は面の淡色・数字の大きさ・細い線のどれかで。
  **角丸カード＋色付き左線は禁止**（本人の決まり）。同じ箱を3つ4つ反復しない
- 見出しは `head()`／`headCss()` を使って大きさをそろえる
- 文字サイズの目安: 見出し21px・小見出し16.5px・本文14.5px・注記12px。行間1.7〜1.9
- **狭い画面（375px）で横に溢れない**こと。`@media (max-width:480px)`（2列なら560px）で縦積みにする
- 動きを付けるときは `@media (prefers-reduced-motion:reduce)` で止める
- 文章は「ですます」。具体的な数字・条件を入れて、そのまま使えるようにする。
  実在の会社名・商品名は書かない（「株式会社サンプル」）。効果の言い切り（治る・必ず痩せる等）は書かない
- リンク先は仮の `ooooo`（入れた人がWidget編集で入れる）
