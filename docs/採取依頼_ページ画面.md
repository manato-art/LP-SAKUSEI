# 採取のお願い ―― 「ページ」画面の挙動一式

目的: `/folders`（サイドバーの「ページ」）を押したときの挙動を、クローンで同じにする。
所要: **15〜20分**。手でコピペする作業はありません。

---

## 準備（1回だけ）

ターミナルで:

```bash
cd ~/Desktop/squadbeyond-clone && npm run mock
```

`[mock] http://localhost:4010` と出たら、**そのターミナルは開いたままに**してください。

## セットアップ（1回だけ）

1. Chrome で本番のアプリを開く（**「新UI」トグルは OFF のまま**）
2. `F12` → **Console** タブ
3. `tools/capture-console/snippet.js` の中身を**全部コピーして貼り付け → Enter**
4. 右下に青いバッジ「採取モード: 待機中」が出れば成功

これ以降、**画面を移動すると自動で保存**されます。
URLが変わらない状態（モーダル・メニューなど）は **`Ctrl + Shift + S`** を押して、
聞かれた名前を入力してください。

---

## 撮ってきてほしい状態（上から順に・名前はそのまま入れてください）

### A. 一覧の基本

| # | 操作 | `Ctrl+Shift+S` で入れる名前 |
|---|---|---|
| 1 | サイドバーの「ページ」を押した直後（フォルダ未選択） | *自動保存されるので操作不要* |
| 2 | フォルダを1つ**クリックして展開**（サブフォルダが出た状態） | `tree-expanded` |
| 3 | サブフォルダを選んで**右に一覧が出た状態** | `list-loaded` |
| 4 | フォルダ行に**マウスを乗せた状態**（☆と⚙が出る） | `folder-hover` |
| 5 | タブ「**お気に入り**」を押した状態 | `tab-favorite` |
| 6 | タブ「**履歴**」を押した状態 | `tab-history` |

### B. 行をクリックしたときの挙動 ★ここが本命

| # | 操作 | 名前 |
|---|---|---|
| 7 | ページの行を**1回クリック**（タイトルが編集状態＋右にドロワー＋行アクションバーが出る） | `row-selected` |
| 8 | 行アクションバーの「**⋯**」を押してメニューを開いた状態 | `row-menu` |
| 9 | 行アクションバーの「**⚙**」を押した状態（ショートカット設定） | `row-shortcut-settings` |
| 10 | **Ctrl+クリックで2行以上選択**した状態（上部に一括操作バー） | `multi-selected` |
| 11 | 右ドロワーの「**パラメータ付きURLの発行**」を押した状態 | `param-url` |

### C. 上部バーの操作

| # | 操作 | 名前 |
|---|---|---|
| 12 | 「**集計期間**」を押してカレンダーを開いた状態 | `period-picker` |
| 13 | 「**配信ステータス**」を押して選択肢を開いた状態 | `status-filter` |
| 14 | 「**並び替え**」を押した状態 | `sort-menu` |
| 15 | 一覧の右端「**⚙**」（列の設定）を開いた状態 | `column-settings` |
| 16 | 「**フォルダ内検索**」に**1件も当たらない文字**を入れた状態 | `search-empty` |
| 17 | ソートのドロップダウン（`PV ↓` など）を開いた状態 | `sort-dropdown` |

### D. 作成まわり

| # | 操作 | 名前 |
|---|---|---|
| 18 | 「**新規ページを作成**」のモーダルを開いた直後 | `create-modal-top` |
| 19 | そのモーダルを**下までスクロール**した状態 | `create-modal-bottom` |
| 20 | エディターで「**HTMLエディター**」を選んだ状態 | `create-modal-html` |
| 21 | 広告媒体の検索に文字を入れて**絞り込んだ**状態 | `create-modal-media-search` |
| 22 | 何も入れずに「作成する」を押して**エラーが出た**状態（出るなら） | `create-modal-invalid` |
| 23 | 左上の**新規フォルダ**アイコンを押した状態 | `folder-create-modal` |

## 守ってほしいこと

- **配信中のページは触らないでください**（一覧のステータスが `配信中` のもの）
- **何も新規作成しないでください**。モーダルは開くだけで、`キャンセル` で閉じてOKです
  - もし作ってしまったら、名前に `【採取用】` を付けて教えてください
- 「新UI」トグルは押さないでください

## 終わったら

Console で `__sbStop()` と打ってから、私に「**ページ画面の採取終わった**」と言ってください。

そのあと私が、匿名化 → 実データが残っていないかの検査 → 画面への反映、を実行します。
実データ（実在の施策名・人名・ドメイン）はリポジトリには一切入りません。
