# 本番アカウントに作った採取用データの後始末（実施済み・ただし完全削除は不可）

## 結論

**Squad beyond に「beyondページの削除」機能は存在しない。**
用意されている唯一の退避操作は **`ステータスを終了にする`**。これを実行済み。

| 種別 | 名前 | 場所 | 対応 | 状態 |
|---|---|---|---|---|
| beyondページ | `【採取用】クローン調査 削除可` | フォルダ「サクラハグ」 | `ステータスを終了にする` を実行 | [x] 一覧から消えた |

## 確認したこと（削除機能が無い根拠）

- 行アクション `⋯` メニュー: `お気に入りに追加` / `フォルダ移動` / `別フォルダへ複製` /
  `beyondページ複製` / `ステータスを終了にする` ―― **削除なし**
- 行アクション `⚙`: ショートカットの表示/並び順/色のカスタマイズ設定 ―― 削除なし
- 基本情報タブ最下部: `更新する` のみ ―― 削除なし

## 現在の状態（無害である根拠）

- 配信ステータス **`終了`** → 一覧の既定フィルタ `終了以外` に出ないので通常は見えない
- 広告媒体 **`媒体/ポストバックなし`** → 外部広告連携なし・ポストバック送信なし
- **一度も公開していない**（公開ボタンは押していない）
- CV計測・ASP連携は未設定
- コンバージョン単価 0 / メディア設定無し

→ 配信も課金も外部送信も発生しない。実質的に無害な状態で残置。

## 人間にお願いしたいこと

完全に消したい場合は、**SquadBeyond のサポート（Channel.io チャット or 担当者）に削除を依頼**するしかない。
急ぎでなければ `終了` のまま放置で問題ない。
